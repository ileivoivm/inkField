How to Submit投稿說明 · a 5-minute walkthrough

No coding required — if you can drag a file, you can share your work.

Share your InkField artwork with the gallery in 5 steps, about 5 minutes. You do not need to know any code.

Before You Submit — Please Read This

An inkField recording is not just a picture — it is your complete creative path: every stroke, every pause, every gesture, every decision. When you submit it to the gallery, you are sharing that path openly for anyone to study, learn from, and be inspired by.

But it goes further than that. In the future, others may be able to pick up where you left off — loading your recording and continuing to paint on top of it, building new work from your foundation. Your path becomes a starting point for someone else's journey.

This is a departure from traditional copyright thinking. It might feel risky. It might also be meaningful — the idea that creative process is not something to lock away, but something worth passing on.

By submitting, you agree to share your creative path openly. You still own your work. But you are giving the world permission to learn from it, and perhaps to stand on it and keep going.

Before you begin

  • A computer with internet access (phone works too, desktop is smoother)
  • A free GitHub account — only needed the first time. Sign up here
1

Paint & click SAVE

Once you've finished your artwork in InkField, click the SAVE button on the right-hand Brush Control panel.

Your browser will download a .json file — just like downloading an image.

The file usually lands in your Downloads folder.

2

Open the submission page

Click this link:

https://ileivoivm.github.io/inkField/gallery/upload.html

3

Drag the file onto the page

Find the .json file you just downloaded and drag it onto the web page, then release.

The page will automatically check whether the file is valid.

✓ Green check — your file is fine.
✗ Red error — something went wrong, save the artwork again and retry.

4

Fill in the details

The page will ask you for three fields:

· Title (e.g. Spring Rain)
· Your name — this will appear on the gallery
· Tags (e.g. landscape, abstract — separate by commas)

Once that's done, click Generate metadata.

5

Submit via GitHub

Click the Submit via GitHub Issue button. A pre-filled form on GitHub will open (sign in if this is your first time).

⚠ Key step that's easy to miss:
Drag the same .json file into the large white Comment box on the GitHub page. It will automatically become an attachment link — don't worry, this is normal.

Finally, click the green Submit new issue button at the bottom of the page.

🎉 Done!

What happens next

  • The maintainer reviews submissions within a few days
  • Once approved, you'll receive a notification comment on your issue
  • Your work will then appear in the gallery

FAQ

Do I really need a GitHub account?

Yes, for now. Signing up is free and takes about a minute — you just need an email address.

Do I lose the rights to my artwork?

You keep full copyright of your work. However, by submitting to the gallery you are sharing your complete creative path — every stroke, every decision — openly for others to study, learn from, and potentially build upon. This is intentional and central to what the gallery is about.

Can I submit AI-generated artworks?

Yes. The gallery welcomes both human and AI submissions — the format and review process are the same.

What is a "Fork"?

A fork means you downloaded someone else's recording from the gallery, loaded it into inkField, and continued painting on top of it — adding your own strokes to their path. When submitting a fork, select Fork on the submission page and enter the source work's ID. The gallery will show the lineage so viewers can trace the creative tree back to its roots.

What if validation fails?

Go back to InkField, click SAVE again, and retry with the freshly downloaded file. If it still fails, please open an issue on GitHub with a description.

It's been a week and I haven't heard back — what now?

Leave a polite comment under your own issue asking for a status update, or reach out to the author Aluan Wang directly.

投稿之前 — 請先讀這段

inkField 的錄製檔不只是一張圖 — 它是你完整的創作路徑： 每一筆、每一次停頓、每一個手勢、每一個決定。當你投稿到 gallery， 你就是把這條路徑公開分享，讓任何人都能觀摩、學習、從中得到啟發。

但不只如此。未來，別人可能可以站在你的路徑上繼續往下畫 — 載入你的錄製檔，在你的基礎上繼續創作。你的路徑，會成為另一個人旅程的起點。

這是一件顛覆傳統版權觀念的事。也許會讓你覺得有風險。 但也許，這件事本身就有意義 — 創作的過程不是該被鎖起來的東西， 而是值得被傳遞下去的。

投稿即代表你同意公開分享你的創作路徑。 你仍然擁有你的作品。但你也給了這個世界學習它的許可， 甚至，站在上面繼續走下去的許可。

你需要準備

  • 一台能上網的電腦（手機也可以，但電腦比較順）
  • 一個免費的 GitHub 帳號，第一次投稿才需要註冊。點這裡註冊
1

畫圖並下載檔案

在 InkField 畫完作品後，按右邊 Brush Control 面板的 SAVE 按鈕。

電腦會自動下載一個 .json 檔案（就像下載一張圖片一樣）。

檔案通常會在你的「下載」資料夾裡。

2

打開投稿頁面

點這個連結：

https://ileivoivm.github.io/inkField/gallery/upload.html

3

把檔案拖進頁面

找到剛剛下載的 .json 檔案，用滑鼠把它拖到網頁上，然後放開。

系統會自動幫你檢查檔案是否正確。

✓ 綠色勾勾＝檔案 OK。
✗ 紅色錯誤＝檔案有問題，回到 InkField 重新存一次再試。

4

填寫作品資料

在頁面上填三個欄位：

· 作品名稱（例如：春雨）
· 你的名字（會顯示在 gallery 上）
· 標籤（例如：山水、抽象，用逗號分開）

填好後按 Generate metadata 按鈕。

5

送出到 GitHub

按 Submit via GitHub Issue 按鈕。會跳到 GitHub 的頁面，上面已經幫你填好大部分資料了（第一次使用需要登入 GitHub）。

⚠ 最容易漏掉的關鍵步驟：
把剛剛那個 .json 檔案，再拖進下面那個大白框（Comment 輸入框）一次。它會自動變成一個附件連結，這是正常的，不用擔心。

最後按頁面最下面綠色的 Submit new issue 按鈕。

🎉 完成！

接下來會發生什麼？

  • 維護者會在幾天內審核你的作品
  • 審核通過後，你會在剛剛那個 issue 下收到一則通知留言
  • 你的作品就會出現在 gallery 裡了

常見問題

一定要用 GitHub 嗎？

目前是的。GitHub 帳號免費，註冊只要一分鐘，需要一個 email 就可以。

我的作品版權會被拿走嗎？

你永遠保有作品的完整版權。但投稿到 gallery 代表你公開分享了完整的創作路徑 — 每一筆、每一個決定 — 讓別人可以觀摩、學習，甚至在未來以你的路徑為基礎繼續創作。這是 gallery 的核心理念，也是你投稿時同意的事。

可以投稿 AI 生成的作品嗎？

可以。gallery 同時接受人類與 AI 的作品，投稿格式與審核流程完全一樣。

什麼是「Fork」？

Fork 的意思是你從 gallery 下載了別人的錄製檔，載入 inkField 後在上面繼續畫 — 把你自己的筆觸加到他的路徑上。投稿 fork 作品時，在投稿頁選擇 Fork，並填入來源作品的 ID。gallery 會顯示作品之間的傳承關係，讓觀者可以沿著創作的樹狀結構追溯回源頭。

驗證失敗怎麼辦？

回到 InkField 重新按一次 SAVE，用新下載的檔案再試一次。如果還是不行，可以到 GitHub 開 issue 說明狀況。

一週了還沒收到回覆怎麼辦？

可以在你的 issue 下留言詢問進度，或直接聯絡作者 Aluan Wang。
